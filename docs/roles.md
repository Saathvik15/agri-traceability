# Roles and Permissions

| Role | Allowed Actions |
| --- | --- |
| Farmer | Create farm and batch; request handoff |
| Logistics / Transporter | Accept handoff; create shipment; record temperature/humidity; deliver shipment |
| Retailer | Mark delivered batch available or withdrawn |
| Regulator | View batches; issue recall |
| Consumer | Only view anonymous QR verification page |
